# Day 1 — Networking Basics

## What is Networking?

Networking is the communication between computers and devices to share data and resources.

## Key Concepts Learned

### IP Address
An IP address identifies a device on a network.

Example:
192.168.100.23

### Subnet Mask
A subnet mask helps determine the network and host portions of an IP address.

Example:
255.255.255.0

### Default Gateway
The default gateway is usually the router that allows a device to communicate with other networks.

### DNS
DNS (Domain Name System) translates domain names into IP addresses.

Example:
google.com → IP address

## Practical Commands

### ipconfig
Used to view network configuration such as:
- IPv4 address
- Subnet mask
- Default gateway

### ping
Used to test connectivity between my computer and another host.

### nslookup
Used to query DNS and find the IP address associated with a domain.

## What I Practiced

I used `ipconfig`, `ping google.com`, and `nslookup google.com` in Windows Command Prompt.
